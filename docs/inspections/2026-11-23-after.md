## Fixed (32 of the 54 baseline findings)

- **ES6MissingAwait, JSIgnoredPromiseFromCall, unresolved `.catch` (main.js).** The leaderboard refresh and score submit run in the background so the frame loop never waits on the network. They are now plain functions that handle both success and failure inside a `.then(ok, fail)` chain. Before, an `async` function was called and its promise was dropped. `lb` now has a JSDoc type (`Leaderboard` typedef in leaderboard.js), so the promise methods resolve.
- **PyInconsistentReturns (server, 5).** `return` inside `with lock:` / `with db:` blocks moved to after the block, so every function has one clear return path, and the lock is released before the return.
- **PyTypeChecker + PyArgumentList (server).** `PreAimServer` now takes the `App` in its constructor and sets `self.app` itself, instead of the attribute being added afterwards in `make_server`. `stop_server` has a type hint.
- **PyAttributeOutsideInit (server, 3).** The `/board` alias is now done in `translate_path` instead of rewriting `self.path`. `close_connection` is set in the handler `__init__` before the base class handles the request.
- **PyUnusedParameter.** The `list_directory` override (directory listing turned off) names its required parameter `_path`.
- **Unused imports.** `PHASE` (main.js), `EDGES` (render.js, logic.test.mjs) removed.
- **JSUnusedLocalSymbols.** Unused `extra` parameter removed from `Renderer.drawBoard`.
- **UnnecessaryLocalVariableJS (2).** `flick` / `pulse` inlined, with short comments.
- **PointlessArithmeticExpressionJS.** `1000 * 0` removed from a test bound.
- **JSCheckFunctionSignatures (5).** JSDoc added for `AudioFX.tone` options and the board `show()` highlight id.
- **JSUnresolvedReference (5 more; 6 of 9 with the `.catch` above).** stress.test.mjs now imports `process` from `node:process` and uses `globalThis` instead of the Node-only `global`.

## Accepted (22 baseline findings + 1 new GrazieStyle note), with reasons

- **CssUnusedSymbol (6): false positive.** `.ok`, `.rk`, `.new`, `.empty` in board.css are all used. board.js adds them at runtime (`className = ok ? 'ok' : 'warn'`, `s.className = cls` for `rk`, `classList.add('new')`, `li.className = 'empty'`), and the static analysis cannot see that.
- **PyPep8Naming (4): required names.** `do_GET` / `do_POST` are the method names `BaseHTTPRequestHandler` dispatches to. `setUp` / `tearDown` are the `unittest` hooks. Renaming any of them would break them.
- **JSUnresolvedReference (3): Node API typings.** `process` in tests/index.js (a CommonJS entry point) and `heapUsed` on `process.memoryUsage()` are Node built-ins. The project has no `package.json` or `@types/node` on purpose (no npm install needed), so the IDE has no types for them. The tests run fine on Node.
- **JSUnusedGlobalSymbols (2).** `window.__preaim.step` is the test/capture hook called from tools/capture.py through the browser, which the JS analysis cannot see. `removeItem` keeps the in-memory storage stub the same shape as the Web Storage API it stands in for.
- **HttpUrlsUsage (2).** The server's startup banner prints `http://localhost` links. It is a local booth server with no TLS on purpose (it works offline on a LAN).
- **GrazieStyle (6).** Grammar-tool suggestions to swap `->` in PLAN.md / STATE.md planning notes for an arrow glyph. Style only, ignored.
